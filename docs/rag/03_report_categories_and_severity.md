# Report Categories and Severity Levels

## Incident Categories

When submitting a report, you must choose one of these incident types:

1. Theft / Robbery — Bag snatching, pickpocketing, robbery.
2. Assault — Physical assault or attack.
3. Fraud / Scam — Online scams, financial fraud.
4. Harassment — Verbal or physical harassment.
5. Vandalism — Property damage.
6. Accident — Traffic accidents, workplace accidents.
7. Fire — Fire incidents.
8. Flood — Flooding events.
9. Suspicious Activity — Unusual or suspicious behavior.
10. Violence — Acts of violence, domestic violence.
11. Other — Any other safety incident.

## Severity Levels

- Low: Minor incident, no immediate danger.
- Medium: Moderate concern (this is the default if not specified).
- High: Serious incident requiring attention.
- Critical: Severe or life-threatening situation that requires immediate response.

## Map Color Coding

On the hotspot map, incidents are color-coded:

- Red (Critical/High): Serious crimes like theft, robbery, violence, verified incidents.
- Orange (High): Assault, violent incidents, fire.
- Yellow (Medium): Accidents, minor incidents, suspicious activity.
- Blue (Low): Fraud, non-violent crimes, flooding.
- Purple: Harassment cases.
- White/Gray: Pending review (only visible to admin officers, not the public).
