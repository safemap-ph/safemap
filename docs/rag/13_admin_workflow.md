# Admin Officer Workflow

## Who Are Admin Officers?

Admin officers are authorized DWSD (Department of Social Welfare and Development) staff who have login access to the SafeMap system. They have the role of "admin" or "moderator" in the system.

## How to Log In

Admin officers log in using their username and password through the admin login section. After logging in, they receive an access token that allows them to use admin features.

## Reviewing Reports — Step by Step

1. Open the Pending Reports Queue to see all reports waiting for review.
2. For each report, review the details: incident type, date, location, description, and any personal details provided.
3. Check if the report seems reasonable and legitimate.
4. Decide the status of the report:

### Option A: Approve for Awareness

- The report will appear on the public heatmap as aggregated heat.
- Personal details (reporter name, contact) are automatically removed.
- The report is marked as "Approved for Awareness."

### Option B: Verify / PNP Confirmed

- The report will appear as an individual verified marker on the map.
- It will be included in official dashboards and statistics.
- A PNP case number can be attached.
- Personal details are automatically removed.
- The report is marked as "Verified."

### Option C: Dismiss

- The report is removed from public view.
- Used for spam, duplicates, or invalid reports.
- Personal details are automatically removed.
- The report is marked as "Dismissed."

## Additional Admin Actions

- Remove personal details from any report manually.
- Generate summary reports and statistics (total reports, reports by status, by category, by severity).
- View the activity/audit log showing all recent actions with timestamps.
- Manage report categories and tags.
- Update emergency hotline numbers, locator data, and safety contacts in the Help Directory.

## Help Directory Management

Admin officers can:

- Add new emergency contacts (name, category, phone, address, coordinates, operating hours).
- Update existing emergency contacts.
- Delete contacts that are no longer valid.
- Seed default emergency contacts for first-time setup.

Changes made to the Help Directory appear immediately in the public Help section and are also used by the AI chatbot when answering questions about emergency contacts.
