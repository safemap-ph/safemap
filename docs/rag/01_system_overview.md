# SafeMap-PH System Overview

SafeMap-PH is a community safety mapping platform for General Santos City (GenSan), Philippines. It allows public users to anonymously report safety incidents, view a hotspot heatmap of approved and verified incidents, access emergency hotlines, and chat with an AI assistant.

## What Public Users Can Do (No Login Required)

1. Ask the AI Chatbot for help about using the map, reporting, or checking hotlines.
2. Submit an anonymous report of a safety incident.
3. View the hotspot map to see approved and verified incidents.
4. Open the "Get Help Now" section to view emergency hotlines and station locations.
5. Track a previously submitted report using a reference code.

## What Admin Officers Can Do (Login Required)

Admin officers are authorized DWSD staff who log in to the system. They can:

1. Open the Pending Reports Queue and review each report.
2. Approve reports for public awareness (shows on heatmap).
3. Verify reports as PNP Confirmed (shows as verified marker on map and included in official dashboards).
4. Dismiss reports that are spam or duplicates.
5. Remove personal details from reports.
6. Generate summary reports and statistics.
7. View audit logs and manage categories and tags.
8. Update hotline numbers, locator data, and safety contacts.

## Map Center

The map is centered on General Santos City at latitude 6.1167, longitude 125.1667.
