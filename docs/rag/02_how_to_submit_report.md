# How to Submit an Anonymous Report

## Step-by-Step Process

1. Tap "Report Incident" (the floating button on the main map screen).
2. Safety First Page: Read the emergency protocol and privacy rules. Check both boxes to confirm.
   - Emergency Protocol: "If you are in immediate danger, call 911 immediately."
   - Privacy Rule: "Your report will be treated with strict confidentiality. We never share your personal information."
3. Tap "Start Anonymous Report" to proceed.
4. Incident Details Page: Select the incident type, set the date and time, and write a description of what happened.
5. Location Details Page: Drop a pin on the interactive map or enter an address. You can specify the barangay and city.
6. Review and Submit Page: Review all details you entered, then tap submit.
7. Report Success Page: You will receive a unique reference code and a safety notice.

## What Happens After You Submit

1. The system checks if all required fields are filled out. If not, it asks you to complete them.
2. The system runs basic safety checks (description must be at least 10 characters, coordinates must be within the Philippines).
3. The report is saved in the anonymous database.
4. It is marked as "Unverified and Pending Review" — it will NOT appear on the public map yet.
5. You receive a reference code in the format SMPH-XXXXXX (example: SMPH-A1B2C3).
6. A safety notice is displayed: "Your report has been submitted and is pending review. Do not confront any suspects directly. In case of emergency, dial 911. Save your reference code for tracking."

## Required Information for a Report

- Title: A brief title of the incident.
- Description: Detailed description (minimum 10 characters).
- Location: Latitude and longitude (drop a pin on the map).
- Category: The type of incident (see report categories).

## Optional Information

- Severity: low, medium (default), high, or critical.
- Barangay name.
- Street address.
- Reporter name (optional, will be removed before publishing).
- Reporter contact (optional, will be removed before publishing).
- Image attachment.

## Privacy and Anonymity

- Reports are anonymous by default.
- If you provide your name or contact, admin officers will remove personal details before the report is made public.
- Your personal information is never shown to the public.
